# Agent notes

Findings that carry across sessions. Read them in this order. Do not read
every file at the start of a session.

## Read at the start of a session

1. `codegen-index.md` — one line per known code-generation symptom, with the
   rule it implies and the ID of the detail section. This is the only notes
   file you read in full.

## Read before you name anything

2. `original-names.md` — the structure names, field names, and translation
   units recovered from the retail binary's own assert and log strings. **A
   name in that file outranks any name you would invent.** Generated by
   `tools/decomp names`; do not edit it by hand.
3. `refactor-debt.md` — functions that match the machine code but still state
   byte offsets. Read it when you touch one of them, or when you want a
   high-value task that is not a fresh reconstruction.

## Read on demand, one section at a time

4. `codegen-rules.md` — source-level idioms that change MSVC6 code generation.
   Open the `FIX-nn` section that the index points at.
5. `codegen-caps.md` — legacy observations about recurring differences. Open
   the `CAP-nn` section that the index points at. Test the observation again.
6. `reccmp-mechanics.md` — reccmp, annotation, and Ghidra importer behavior.
   Open the `TOOL-nn` section that the index points at.
7. `shared-globals.md` — retail data globals that cross translation units.
   Read it when your target references an unfamiliar data address.

## Machine readable

8. `caps-registry.tsv` — the legacy audit queue. Its rows do not prove a
   compiler quirk and do not suppress candidates.

## Writing a new note

- Add one line to `codegen-index.md`, and at most one section to the matching
  detail file. Keep a new section to about eight lines.
- Start the section title with the symptom, not the conclusion. The next agent
  searches by what the diff looks like.
- Do not add a row to `caps-registry.tsv`. Store source trials with
  `tools/decomp experiment`.
- Keep notes general. Do not name a function, parameter, or field. Describe the
  shape instead.
- Follow the `ste-writing` skill at `./.pi/skills/ste-writing/SKILL.md`.
- Before you add a note, check that the index has no row for it already. A
  duplicate costs every later session context and gives nothing back.
